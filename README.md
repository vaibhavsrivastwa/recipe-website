# 🍴 Delicious Recipes Website

A simple, responsive recipe website built with **HTML** and **CSS**.

## ✨ Features
- Home page with introduction and featured recipes
- 5 recipe pages: Biryani, Chicken Tikka, Pizza, Egg Roll, and Tacos
- Each recipe includes:
  - Title and image
  - Ingredients list
  - Step‑by‑step instructions
  - Preparation time and difficulty level
- Consistent navigation bar and footer
- CSS styling with:
  - Gradient header
  - Flexbox grid layout
  - Hover effects on cards and buttons
  - Responsive design for mobile screens
